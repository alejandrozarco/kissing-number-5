# Dimension-3 code used by `numerics/kissing5/`

`k3.py` (SDP formulations), `polyk.py` (polynomial toolkit, from alejandrozarco/thomson-n7-log) and
`round_k3.py` (exact rounding), unchanged from
[kissing-number-3](https://github.com/alejandrozarco/kissing-number-3) (`numerics/kissing3/`), where they
are documented. `numerics/kissing5/k5.py` and `round_k5.py` import them and replace the kernels of $`S^2`$
by those of $`S^4`$.
